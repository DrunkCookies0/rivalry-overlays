Three quick steps, takes about two minutes. You can reopen this guide any time from the tray icon (Setup guide).

Rocket League match feed

The overlay reads live match data (score, clock, boost, goals) straight from Rocket League's built-in stats output. This app already wrote the small config file that turns that output on. No mods, no plugins, tournament safe.

Mock feed is on (test data from the app's mock mode, not a real match).

Get the scenes into OBS

The overlay graphics load into OBS as browser sources. Click the button and the app does all of it: finds OBS, switches on the connection it needs, starts it, and builds the 7 broadcast scenes. There is no password to find or type.

  • Find OBS Studio
  • Switch on its connection
  • Start OBS
  • Connect to it
  • Build the 8 scenes
Your other scene collections are left alone.

Manual

Connect by hand

If the automatic setup can't reach your OBS (a portable copy, say), connect it yourself.

  1. In OBS, open the Tools menu, click WebSocket Server Settings.
  2. Turn on Enable WebSocket server. If it shows a password, copy it.
  3. Paste the password below (leave blank if there wasn't one), click Connect.

Import a file instead

No WebSocket needed. Download the collection and import it in OBS.

DOWNLOAD SCENE COLLECTION
  1. In OBS, click the Scene Collection menu.
  2. Click Import, pick rivalry-casterverse.json.
  3. Open the menu again and switch to RIVALRY Casterverse.
All 8 scenes arrive pre-wired. Keep this app running whenever OBS is open.

The control panel

The control panel is where you run the show: save your league API key (Setup tab, once), find and load your league match — team names, logos and rosters come with it — then drive the series score, casters, schedule and scene switching. Everything pushes to the overlay instantly. Two ways to use it:

Recommended

Run it as an OBS dock

It lives inside OBS, so the whole broadcast is one window on match night.

  1. In OBS, open the Docks menu.
  2. Click Custom Browser Docks.
  3. Paste the address below into a new row, name it RIVALRY, click Apply.
